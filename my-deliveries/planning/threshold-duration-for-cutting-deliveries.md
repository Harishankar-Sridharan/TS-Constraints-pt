# Duração limite para cortar entregas

Este valor define o **duração mínima** abaixo da qual uma visita **não pode ser mais dividida** em várias partes.

**Formato:** HH:MM

**Exemplo:**

* Um cliente tem uma **Duração da visita** de 04:00
* O **Duração de uma parte de uma visita dividida** é definida para 01:00:00, permitindo que a visita seja dividida.
* O **Duração limite para dividir visitas** está definida para 01:30:00, o que significa que após a divisão, nenhuma parte da visita pode ser mais curta que 1 hora e 30 minutos.
