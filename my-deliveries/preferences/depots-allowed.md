# Depósitos permitidos

Os depósitos representam os armazéns dos quais as visitas são abastecidas. No entanto, nem todos os clientes estão ligados a todos os depósitos. O **Depósitos autorizados** definição especifica quais depósitos estão autorizados a atender cada cliente.

Para alguns clientes, um armazém específico deve ser usado. Isso significa que a visita deve ser abastecida a partir de um depósito designado antes que o recurso possa executar o serviço.

**Formato**: Caractere
