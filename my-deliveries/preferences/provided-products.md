# Produtos fornecidos

Esta restrição especifica os tipos de produtos aos quais um recurso deve ter acesso para realizar uma visita em um determinado local.

**Formato:** Lista de texto, com cada item separado por vírgulas.

**Exemplo:**\
Se um recurso precisa parar em um depósito para recolher ferramentas de jardinagem antes de concluir uma visita, você pode especificar **"jardinagem"** como o produto exigido.\
Pelo menos um depósito deve fornecer este produto para que o recurso possa realizar a visita.
