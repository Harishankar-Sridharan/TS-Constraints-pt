# Compatibilidade com os recursos

Esta restrição identifica os requisitos específicos que uma visita necessita, os quais devem ser atendidos para que um recurso realize essa visita.\
Liste todos os critérios necessários como palavras separadas por vírgulas. Um máximo de 64 critérios diferentes pode ser usado em todos os arquivos de visitas e recursos.

**Formato:** Lista de palavras separadas por vírgulas

**Exemplo**; Encanamento/Eletricidade
