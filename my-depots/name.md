# Nome

Este valor é usado para identificar exclusivamente o depósito. O nome pode ser nome/identificador do depósito/armazém.&#x20;

**Formato:** caractere

**Exemplos:**

* Depósito A

Atribuir um valor a este campo é **obrigatório**, e é recomendado usar um **nome único** para cada local para evitar confusão durante o planejamento.
