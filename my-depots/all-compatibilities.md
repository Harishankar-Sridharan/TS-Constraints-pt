# Todas as Compatibilidades

Quando o **Compatibilidade com os recursos** a restrição é aplicada (especialmente com múltiplos critérios), esta configuração permite que você especifique se **apenas uma** um critério da lista é suficiente ou se **todos os critérios** devem ser atendidos.

**Formato:** Sim / Não

**Exemplo:** Todas as compatibilidades - Não
