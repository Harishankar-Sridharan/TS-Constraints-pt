# Recarregar/Descarregar

Esta restrição controla se um recurso tem permissão para recarregar no depósito durante uma rota. Quando ambos **Primeira parada no depósito** e **Última parada no depósito** os constrangimentos são aplicados, o recurso não recarregará no depósito durante a rota. Nesse caso, o recurso carregará apenas uma vez (no início ou no fim) ou duas vezes (tanto no início quanto no fim).

Defina a opção para **Proibido** para impedir a recarga durante a rota, ou para **Permitido** para permitir. A configuração padrão é Proibido.

**Formato**_: Sim /_ Não

**Exemplo**: Recarregar/Descarregar - Não
