# Duração por unidade para cada visita

Este valor representa o tempo necessário pelo recurso para entregar ou recolher **uma unidade de produto durante uma visita ao cliente**. O tempo inserido é multiplicado pelo **Quantidade 1** valor da visita. Esta restrição aplica‑se **apenas à restrição Quantidade 1** e não afeta os outros 23 tipos de quantidade disponíveis.

**Formato:** HH:MM:SS

**Exemplo:**\
Para uma entrega de **10 pacotes** a um cliente, se o tempo de descarga para um único pacote for **3 minutos**, insira **00:03:00** (ou **180 segundos**) para **Duração de carregamento/descarga por unidade para cada visita**, e defina o **Quantidade 1** valor para **10**. O tempo total de descarga no local do cliente será então **30 minutos** (3 minutos × 10 pacotes).

Esta duração depende da **capacidade do veículo**.
