# Número máximo de recargas/descarregamentos

Esta restrição permite que você **limitar o número de recargas por dia** quando a recarga é permitida pelo **Recarregar/Descarregar** restrição. Define o número máximo de operações de recarga que um recurso pode realizar em um único dia.

**Formato:** Número

**Exemplo**: HH MM

**Nota:** Esta restrição depende do **capacidade do veículo**.
