# Tempo de trabalho semanal

**Este valor define o número máximo de horas de trabalho que o recurso pode realizar a cada semana.**\
A cota semanal deve estar totalmente contida nas janelas de horário de trabalho definidas para o recurso.

**Formato:** HH:MM

**Nota:**\
A definição de “semana” depende da configuração:

* Se o **Dias Trabalhados** a restrição usa datas do calendário, o sistema usa o **semana do calendário**.
* Caso contrário, o planejador usa um **intervalo de 7 dias** como referência semanal.

**Exemplo:**\
_**Tempo de Trabalho Semanal** – 40:00_
